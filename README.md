# Numerica - Progressive Gaming Web App 🎮

A modern Progressive Web App (PWA) featuring logical games.


## 🎮 Games

### Tic-Tac-Toe 🎯
- Classic 3x3 strategy game
- Play against a friend (2 players mode)
- Challenge the AI (single player mode)
- Track wins, losses, and draws

### Memory Card Game 🃏
- Test your memory and concentration
- 8 pairs of colorful emoji cards
- Track your moves and time
- Scoring based on performance

### Minesweeper 💣
- Classic mine-sweeping puzzle game
- Three difficulty levels (Easy, Medium, Hard)
- Safe first click guaranteed
- Left-click to reveal, right-click to flag
- Timer and mine counter tracking
- Strategic gameplay with logic-based deduction
### Whack-a-Mole 🦫
- Classic arcade reflex game
- Test your reaction speed and hand-eye coordination
- Three difficulty levels (Easy, Medium, Hard)
- Click the moles as fast as you can
- High score tracking for each difficulty
- Engaging animations and smooth gameplay
